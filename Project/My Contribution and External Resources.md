My Contribution
1. Art Assets and Visual Design

I created several original art assets for the project using Adobe Photoshop. These include:

Thorn obstacle sprites
Player health bar UI elements
Various visual adjustments and asset integration within game scenes

In addition to original assets, I also modified and adapted external resources to better fit the game's visual style, color consistency, and gameplay requirements.

Overall, I was responsible for ensuring that all visual elements maintain a coherent aesthetic style throughout the game.

2. Animation System

I was responsible for setting up and implementing the animation system in Unity.

My work included:

Creating Animator Controllers
Designing animation state machines
Configuring animation transitions and conditions
Implementing character animation logic and state switching

These systems allow both the player character and interactive objects to respond smoothly to different gameplay states and events.

3. Programming and Gameplay Systems

I developed a significant portion of the game's scripts and gameplay systems.

My core contributions include:
Player movement and interaction mechanics
Interactive object logic
Scene transition system
Save point and game state management
Various supporting gameplay features and scripts
AI-assisted development:

Some scripts (e.g., character-related prototype logic and utility functions) were initially generated or assisted by AI tools. I independently reviewed, modified, debugged, and integrated these scripts into the project to ensure correctness and compatibility with the overall architecture.

Development responsibilities:

I also participated in continuous debugging, testing, and optimization to improve system stability and gameplay experience.

4. Level Design and Scene Construction

I built all game scenes and level layouts in Unity.

My responsibilities included:

Environment construction and layout design
Object placement and scene composition
Gameplay flow and pacing design
Exploration route design
Checkpoint and interaction placement

This work ensured that the gameplay progression is clear, structured, and aligned with the intended player experience.

5. Game Design

I designed the core gameplay rules and overall structure of the game.

While the project follows some common conventions of the 2D exploration-action genre, the gameplay mechanics, progression system, scene structure, and interaction design were developed based on my own design goals and iteration process.

6. External Resources and Asset Usage

This project also integrates external resources to support development:

Visual Assets (from Itch.io)

Some character sprites, enemy assets, and base visual resources were obtained from the Itch.io asset platform. These assets were selected based on style consistency and then adapted (e.g., scaling, color adjustment, animation integration) to fit the game’s visual direction.

Audio Assets

Background music and sound effects were sourced from multiple open-license audio websites. All audio materials were chosen to match the game’s atmosphere and were adjusted when necessary for consistency and balance.

AI-assisted Content

AI tools were used to assist in generating initial code drafts and supporting implementation ideas. All AI-generated content was reviewed, modified, and integrated manually to ensure it met the project’s design requirements and functional correctness.
