# Download & Run the Game
Download the latest playable build from GitHub Releases:
https://github.com/zzzzerd/GameProject-Anomaly/releases/tag/v2.0

Windows (Executable Version)
Download the .zip file from the release page
Extract the zip file to your local folder
Open the extracted folder
Double-click Anomaly.exe (or the main .exe file) to run the game

⚠️ Important: Make sure all files in the folder are kept together (e.g. *_Data folder must be in the same directory as the .exe), otherwise the game will not run properly.
